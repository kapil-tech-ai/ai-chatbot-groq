# My First AI Chatbot

This is a simple, interactive AI Chatbot built using Python and the Groq API. 

## Features
- It uses the Llama 3 model (via Groq) to generate human-like responses.
- It runs in a continuous loop, allowing you to chat back and forth.
- Type 'exit' to stop the chatbot.

## Technologies Used
- Python
- Groq API (LLM)

## How to Use
1. Install the required library: `pip install groq`
2. Replace the `api_key` in the code with your own Groq API Key.
3. Run the Python file and start chatting!
